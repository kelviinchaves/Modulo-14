# Landing Page – Módulo 14

Projeto criado como atividade prática para estudar desenvolvimento web utilizando HTML, CSS e Bootstrap.

## 📌 Sobre

Esta landing page foi desenvolvida como parte das minhas atividades na formação em desenvolvimento web. O objetivo foi aplicar semântica HTML, estilização CSS e uso de frameworks utilitários (Bootstrap) para criar uma página responsiva e visualmente consistente.

## 🚀 Tecnologias Utilizadas

- HTML5  
- CSS3  
- Bootstrap (v4/v5 – conforme biblioteca usada)  
- JavaScript (pode ser adicionado futuramente)  
- Git/GitHub  
- Deploy via Vercel

## 🧠 O que aprendi com este projeto

- Estrutura HTML semântica  
- Layout responsivo com Bootstrap  
- Organização de arquivos em projeto real  
- Publicação de projeto no Vercel  
- Conscientização sobre boas práticas de front-end
